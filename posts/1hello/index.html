1 使用Hugo本地搭建和调试

Hugo 是用 Go 语言写的静态网站生成器，里面提供各类博客模板，官网是https://gohugo.io/。

1.1 开始搭建

创建一个Hugo工程文件夹，例如: F:\Blog。 在命令行中，输入命令：

cd F:\Blog
hugo new site blog

1.2 安装主题

根据主题模板中的提示一步一步安装。关键步骤是修改Blog\blog\hugo.toml文件。

1.3 创建博客文章

用 Hugo 命令创建一篇文章:

cd blog\content\en\posts
hugo new Hello.md

在文件夹Blog\blog\content\en\posts下就可以看到新建好的文件了，打开后可以进行内容编辑。

1.4 本地预览调试

执行Hugo命令可以在本地预览网站的内容和效果：

hugo server

命令运行成功后，可以在 http://localhost:1313/ 中预览网站。如果在线修改Hello.md内容，网页也会实时更新。

2 发布到Github Pages仓库

本地调试完成后，将Blog\blog\public下的内容复制到git repo，通过VS Code的git发布到远程即可。
